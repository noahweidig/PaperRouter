# Use it

## One paper

1. Select an item in Zotero.
2. Right-click → **Send to Collections…**, or click the PaperRouter icon in the toolbar.
3. Pick the collections that fit and confirm.

If you select a child item (a PDF, snapshot or note), PaperRouter works on its parent paper.

## The dialog

- **Already in** lists the collections the item belongs to. **Best matches** lists the top suggestions, each with a confidence of High, Medium or Low. The number is in the tooltip.
- Hover a row or chip to see why it was suggested: the words that matched and the most similar papers already filed there.
- Search filters the list. Keyboard: ++enter++ confirms, ++escape++ cancels, ++slash++ focuses search.
- Drag the **threshold slider** to hide low-confidence suggestions. The default minimum is set in [Settings](settings.md).
- **Retry** re-ranks after you reject some suggestions. Rejected collections go on a per-item blacklist and are down-ranked next time.

The number of collections pre-selected is capped (default 4). A child collection is not suggested when its parent is already a strong match.

## Many papers

Use [batch mode](batch.md) to file a whole selection in one window.
